# 멍화분 🌱

폰을 화면이 바닥을 향하게 엎어두면 식물이 자라고, 중간에 집어 들면 시드는 디지털 디톡스 웹앱이에요.
서버나 데이터베이스 없이, 기록은 폰 안(브라우저 저장소)에만 저장돼요.

## 폴더 구성

```
www/                  ← 앱 본체 (이 폴더만 올리면 웹으로 배포 끝)
  index.html          화면 구성
  style.css           디자인
  plant.js            식물 그림 그리기
  storage.js          기록 저장 (폰 안에만)
  app.js              핵심 로직 (센서, 타이머, 시듦 판정)
  manifest.webmanifest, sw.js, icons/   홈 화면 추가·오프라인 실행용
capacitor.config.json ← 나중에 안드로이드 앱으로 포장할 때 쓰는 설정
package.json
```

## 동작 규칙

- 목표 시간(15/30/60분 또는 1~300분 직접 입력)을 고르고 시작 → 폰을 엎으면 시간이 쌓여요.
- 폰을 들면 5초 안에 다시 엎어야 해요. 못 하면 시들어요.
- 키우는 동안은 화면이 자동으로 꺼지지 않고, 엎어두면 화면이 까맣게 바뀌어요(배터리 절약).
- 그래도 엎어둔 채 화면이 꺼졌다면 꺼져 있던 시간까지 계산하고, 다시 켰을 때 10초 안에 엎으면 이어가요.
- 폰을 든 상태로 다른 앱으로 가면 시들어요.
- 센서가 없는 기기(컴퓨터)에서는 "엎어두기 / 들기 전환" 테스트 버튼이 나와요.

알려진 한계: 웹앱은 화면이 꺼진 동안 센서를 못 읽어요. 그래서 엎어둔 채 화면을 끄고, 몰래 들어서 다른 앱을 쓰다 돌아오면 잡아내지 못해요. 안드로이드 앱으로 포장한 뒤에 보완할 수 있어요.

## 내 컴퓨터에서 실행해 보기

`www` 폴더에서 아무 정적 서버나 켜면 돼요. 예:

```
npx serve www
```

## 나중에 안드로이드 앱으로 만들기 (Capacitor)

웹 코드를 그대로 안드로이드 앱 안에 넣는 방식이에요. Node.js와 Android Studio가 설치돼 있어야 해요.

```
npm install
npx cap add android     # android 폴더 생성 (처음 한 번)
npx cap sync android    # www 내용을 앱에 복사 (코드 고칠 때마다)
npx cap open android    # Android Studio에서 열어서 실행·빌드
```

`capacitor.config.json`의 `appId`(`com.example.phoneplant`)는 플레이 스토어에 올리기 전에 본인만의 이름(예: `com.내이름.phoneplant`)으로 바꿔주세요. 한 번 올리면 바꿀 수 없어요.
